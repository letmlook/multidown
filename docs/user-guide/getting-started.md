# 快速上手

## 创建 HTTP 下载

1. 点击工具栏的新建任务按钮，或从“任务”菜单打开新建任务。
2. 粘贴 `http://` 或 `https://` 地址。
3. 等待应用探测文件名、大小和断点续传能力。
4. 确认保存目录、文件名及可选的认证信息或请求头，然后开始下载。

服务器不支持 Range 请求时，任务会退化为单连接下载。需要登录的资源可在任务对话框中提供 Basic/Bearer 认证、自定义请求头、Cookie 或 User-Agent。

## 管理任务

任务列表和右键菜单提供暂停、继续、取消、删除、失败后重试、重新下载、打开文件及打开所在目录等操作。删除任务时注意确认是否同时处理本地文件。

应用会周期保存下载进度。正常退出后，下次启动可恢复未完成任务；远端文件的 `ETag` 或 `Last-Modified` 变化时，为防止文件损坏，应用会重新下载整个文件。

## 其他添加方式

- 从剪贴板添加单个或批量 HTTP(S) 地址。
- 粘贴磁力链接、选择或拖入 `.torrent` 文件，详见 [BitTorrent 指南](./bittorrent.md)。
- 通过浏览器右键菜单或下载接管发送链接，详见[浏览器扩展指南](./browser-extension.md)。
- 使用 `multidown://add?url=...` 深链；URL 参数必须正确编码。

## 队列、批次与计划任务

- 队列用于限制一组任务的并发数和执行顺序；全局并发上限与队列上限会共同生效。
- 批次用于一次导入多条 URL、统一命名和查看聚合进度。
- 分类规则可按扩展名或域名选择保存目录。
- 定时调度支持开始下载、暂停全部、继续全部以及临时限速。

这些行为可在“选项”的队列、批次、分类规则和定时调度页面管理。常用设置见[设置说明](./settings.md)。

## 导入与导出

任务菜单支持将任务列表导出为 JSON，或从兼容的 JSON 文件导入。导入前请检查其中的 URL 和本地路径；导入任务不会自动搬移已有文件。
