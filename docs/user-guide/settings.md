# 设置说明

本页按使用目的归纳“选项”中的设置。修改后请保存；标注需要重启的项目不会立即影响现有任务。

## 启动与交互（选项 → 常规）

- “系统启动时运行”控制开机自启。
- “监视剪贴板”会在复制 HTTP(S) 或磁力链接并切回应用时显示下载信息。
- “显示开始下载对话框”控制新建任务与浏览器发来的任务是否先弹确认。
- “显示下载完成对话框”控制下载完成时是否弹出应用内完成弹窗。该弹窗把**所有未确认的完成条目聚合在同一个窗口**里，连续完成不会刷屏，每条都能直接“打开文件”或“打开所在目录”。它与系统通知是**互相独立**的开关：关掉“下载完成时显示系统通知”不会关掉这个弹窗，反之亦然。
- 重复链接可选择询问、跳过、覆盖或重命名。覆盖可能替换已有文件，建议保留默认“询问”。

## 保存位置（选项 → 保存至）

默认保存路径留空时使用系统下载目录。“使用上次的保存路径”会让新任务继承最近选择。分类规则可按域名或扩展名覆盖默认目录；创建任务时的手动选择优先级更高。

这个目录同时是**删除任务时的安全边界**：勾选“同时删除文件”只会删除解析后仍位于该目录之内的目标，越界目标会被拒绝。留空时无法校验边界，删除文件选项将不可用，因此建议保持一个明确的默认保存目录。

## 连接、性能与恢复（选项 → 连接）

- 每任务最大连接数控制 HTTP 分段并发；更多连接不一定更快，也可能触发服务器限制。
- 全局最大并发任务数会与队列上限共同生效。
- 自动重试次数针对临时网络错误；持续的鉴权或路径错误不会因重试而解决。
- 全局下载限速单位为 KB/s，`0` 表示不限速。
- 请求超时影响连接和读取等待。
- 进度保存间隔越短，异常退出后的回退越少，但磁盘写入更频繁；`0` 表示不周期保存（只有关键状态变化时落盘）。

应用每次启动都会自动恢复未完成的任务：HTTP 任务从持久化的区间状态续传，种子会话与做种状态一并恢复，你主动暂停的任务保持暂停。恢复判定、隔离文件与恢复警告见[快速上手](./getting-started.md#启动恢复)。

## 浏览器捕获（选项 → 常规）

“允许浏览器扩展接管下载”是总开关。域名黑名单一行一个域名，匹配时其子域名也不会被接管。安装和身份验证见[浏览器扩展指南](./browser-extension.md)。

## HTTP 代理（选项 → 代理服务器）

可选择不使用代理、使用系统设置或手动配置。代理管理提供规则分流，但当前 `domain_contains` 会对完整 URL 做子串匹配，可能误命中 userinfo 或路径；使用窄而明确的模式，并在隐私敏感场景实际验证出口。TLS 证书始终严格验证；自签环境应把可信 CA 加入系统信任库。

HTTP 代理与 BT 专用 SOCKS5 代理是两套配置，不会自动互相继承。

## BitTorrent（选项 → BitTorrent）

DHT、本地发现、监听端口、上传限速、peer 上限、做种策略和 SOCKS5 代理的含义见 [BitTorrent 指南](./bittorrent.md)。监听端口、DHT 与代理在重启应用后生效。

**peer 上限对已存在的种子走的是另一条生效路径**：恢复出来的种子已经在会话里，重新添加会忽略新传入的参数，所以上限取自会话级配置。改完 peer 上限后请重启应用。

## 自动化管理（选项 → 分类规则 / 队列管理 / 批次管理 / 定时调度）

- 分类规则按优先级匹配扩展名或域名。
- 队列配置任务组的并发和顺序；暂停的队列不会启动新任务。
- 批次管理多 URL 导入、命名模板和失败重试；删除批次不会连带删除批次已创建的下载任务。
- 定时调度支持单次、每日、工作日、周末或按星期重复，可执行开始下载、暂停、继续和限速。

跨午夜的限速时段可正常工作。修改自动化前，建议先用少量测试任务验证路径和时间设置。

## 通知与声音（选项 → 通知与声音）

可分别控制下载完成和失败的系统通知。若开关已启用但没有通知，请检查操作系统通知权限和勿扰模式——这两个开关与应用内的完成弹窗互不影响。
