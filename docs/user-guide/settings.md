# 设置说明

本页按使用目的归纳“选项”中的设置。修改后请保存；标注需要重启的项目不会立即影响现有任务。

## 启动与交互

- “系统启动时运行”控制开机自启。
- “监视剪贴板”会在复制 HTTP(S) 或磁力链接并切回应用时显示下载信息。
- 开始和完成对话框控制任务创建与完成时是否弹窗。
- 重复链接可选择询问、跳过、覆盖或重命名。覆盖可能替换已有文件，建议保留默认“询问”。

## 保存位置

默认保存路径留空时使用系统下载目录。“使用上次的保存路径”会让新任务继承最近选择。分类规则可按域名或扩展名覆盖默认目录；创建任务时的手动选择优先级更高。

## 连接、性能与恢复

- 每任务最大连接数控制 HTTP 分段并发；更多连接不一定更快，也可能触发服务器限制。
- 全局最大并发任务数会与队列上限共同生效。
- 自动重试次数针对临时网络错误；持续的鉴权或路径错误不会因重试而解决。
- 全局下载限速单位为 KB/s，`0` 表示不限速。
- 请求超时影响连接和读取等待。
- 进度保存间隔越短，异常退出后的回退越少，但磁盘写入更频繁；`0` 表示不周期保存。

## 浏览器捕获

“允许浏览器扩展接管下载”是总开关。域名黑名单一行一个域名，匹配时其子域名也不会被接管。安装和身份验证见[浏览器扩展指南](./browser-extension.md)。

## HTTP 代理

可选择不使用代理、使用系统设置或手动配置。代理管理和分流规则允许按 URL 主机选择不同代理。TLS 证书始终严格验证；自签环境应把可信 CA 加入系统信任库。

HTTP 代理与 BT 专用 SOCKS5 代理是两套配置，不会自动互相继承。

## BitTorrent

DHT、本地发现、监听端口、上传限速、peer 上限、做种策略和 SOCKS5 代理的含义见 [BitTorrent 指南](./bittorrent.md)。监听端口、DHT 与代理在重启应用后生效。

## 自动化管理

- 分类规则按优先级匹配扩展名或域名。
- 队列配置任务组的并发和顺序。
- 批次管理多 URL 导入、命名模板和失败重试。
- 定时调度支持单次、每日、工作日、周末或按星期重复，可执行开始下载、暂停、继续和限速。

跨午夜的限速时段可正常工作。修改自动化前，建议先用少量测试任务验证路径和时间设置。

## 通知

可分别控制下载完成和失败通知。若开关已启用但没有通知，请检查操作系统通知权限和勿扰模式。
